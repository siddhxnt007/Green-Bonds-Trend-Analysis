## Green Bonds Trend Analysis Project

## Project Objective
A data pipeline that loads, cleans, transforms, and analyzes India's green bond data, then generates business insights, visualizations, and a final PDF report.

## Overview

This project runs an end-to-end analysis pipeline:

1. Load raw green bond data
2. Clean the dataset and save the cleaned version
3. Transform the data for analysis
4. Analyze trends and generate business insights
5. Visualize key metrics as a graph/chart
6. Report — compile everything into a PDF report
